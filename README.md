# homebrew-tap

Homebrew tap for [syokan](https://github.com/wwwyo/syokan) — LLMs summon rich UI.

```bash
brew install wwwyo/tap/syokan
```

Supported: macOS (arm64 / x86_64) and Linux (arm64 / x86_64). Windows is not supported.

`Formula/syokan.rb` is generated and pushed by [syokan's release workflow](https://github.com/wwwyo/syokan/blob/main/.github/workflows/release.yml) on every release. Do not edit it here — see [AGENTS.md](./AGENTS.md).
